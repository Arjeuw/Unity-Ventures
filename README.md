# 💰 Savings Management System

## 📌 Project Description

The **Savings Management System** is a simple and user-friendly web application designed to help individuals manage their personal finances efficiently. It allows users to track daily expenses, monitor transactions, record rewards earned, and keep track of coupons used.

The application features a modern **green and black UI theme**, providing a clean and visually appealing experience.

---

## 🚀 Features

* ➕ Add Income, Expenses, Rewards, and Coupons
* 📊 Real-time Balance Tracking
* 🔴 Highlights unnecessary expenses in red
* 🎁 Tracks rewards gained
* 🏷 Tracks coupons used
* 🖱 Interactive buttons and responsive UI
* 🧾 Displays transaction history

---

## 🛠 Technologies Used

* **HTML** – Structure of the application
* **CSS** – Styling (Green & Black Theme)
* **JavaScript** – Functionality and interactivity

---

## 📂 How to Run the Project

1. Download or copy the project files
2. Open the `main.class` file in vs code
3. Start adding your transactions and track your savings
